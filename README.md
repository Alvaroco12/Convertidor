## Requisitos
- Java (JDK 17+)

## Descargar RARS
RARS (RISC-V) se descarga desde GitHub Releases:
https://github.com/TheThirdOne/rars/releases

Descarga el `.jar` (por ejemplo `rars1_6.jar`) y renómbralo a `rars.jar`.
Colócalo en la carpeta:
`tools/rars.jar`

## Ejecutar (modo consola)

java -jar tools/rars.jar nc src/main.asm
